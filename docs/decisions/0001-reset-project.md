# 0001: Reset the project to a learning core

## Status

Accepted on 2026-08-13.

## Context

The previous repository accumulated a web product, authentication, persistence, Memory, RAG,
MCP, sandboxing, multi-Agent workflows, deployment, and payment preparation. Most implementation
was generated by AI, so the owner could run the system but could not confidently explain or change
its core behavior.

## Decision

Keep the old tree under `v1-ai-generated` and replace the active codebase with a minimal TypeScript
CLI. Reintroduce capabilities one at a time, beginning with the raw model protocol and deterministic
repository tools.

## Consequences

- The new `main` temporarily has no Agent functionality.
- Product and deployment work is intentionally discarded.
- Each future capability requires a learning question, a small implementation, and an eval result.
- The old implementation remains available for comparison but is not a source to copy from.
